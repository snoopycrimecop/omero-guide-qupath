How to install OMERO extension for QuPath
=========================================

Description
-----------

In this section, we will cover the steps required to install the
OMERO plugin for QuPath.

Installation
------------

- Download QuPath `v0.7.0 <https://qupath.github.io/>`_.
- Launch QuPath.
- Go Extensions > Extension Manager
- Add the QuPath OMERO extension and select "Install optional dependencies"
- Restart QuPath
